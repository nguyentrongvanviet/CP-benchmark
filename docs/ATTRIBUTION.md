# Attribution and source distinctions

Codeforces public metadata and linked problem/submission pages originate at https://codeforces.com/ . Original links are retained on every record. Metadata was collected through the official public API; statement HTML access from this environment returned an access challenge.

Supplemental statements and editorials are imported from **Open R1, `open-r1/codeforces`**, https://huggingface.co/datasets/open-r1/codeforces , pinned revision **fbe3f6e903ee854eec2e69e9d96d0306cde59baf**. The dataset card declares **CC BY 4.0**: https://creativecommons.org/licenses/by/4.0/ . Changes in this project: select descriptive columns, match current Codeforces IDs, normalize limits, attach provenance, omit official/generated tests and generated checkers. Preserve this attribution when redistributing the imported corpus. Original Codeforces problem authors retain their underlying rights; a dataset's declared license is not an independent verification of upstream authorship or permissions.

No downloaded reference program or generated checker is executed. No invented solution is substituted for unavailable accepted source. Research users should cite the original dataset and Codeforces, and describe corpus transformations and access dates rather than attributing statements to CPBench.
